# 코딩테스트 알고리즘 12주 커리큘럼

파이썬으로 코딩테스트(중급 기본 알고리즘)를 준비하기 위한 12주 학습 자료 저장소야.
주력 플랫폼은 **프로그래머스**(백준은 서비스 상황이 불안정해서 참고용).

## 사용 방법

- 각 주차 폴더에는 `lecture.md`(개념 설명), `problems.md`(추천 문제 목록), `solutions/`(문제별 빈 `.py` 스텁)가 들어있어.
- **개념 설명과 문제만 여기서 받고, 실제 코드는 인텔리제이에서 이 폴더를 열어 직접 타이핑**하는 방식으로 진행해.
- `solutions/`의 `.py` 파일은 함수 시그니처와 `# TODO`만 채워져 있고, 정답 코드는 들어있지 않아.
- 학습 페이스: **주 2회, 회당 30분~1시간**. 수준은 기본기는 있지만 중급 문제를 안정적으로 풀고 싶은 정도.

## 학습 순서

1. 해당 주차의 `lecture.md`를 먼저 읽는다 (왜 필요한가 → 핵심 개념 → 코드 예제 → 감으로 익히는 기준표 순서).
2. `problems.md`의 추천 문제를 순서대로 푼다.
3. `solutions/`의 스텁 파일을 인텔리제이에서 열어 직접 구현한다.
4. 세션이 끝나면 `progress.md`에 진행 상황(완료한 문제, 막힌 부분, 다음 목표)을 기록한다.
